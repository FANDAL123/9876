# Отчёт по проекту «Прогноз задержки вылета с экономической оценкой»

## 1. Цель работы

Цель проекта — построить модель машинного обучения для прогнозирования задержки вылета рейса более чем на 15 минут (`delayed_15`) и оценить потенциальный экономический эффект от использования такой модели в авиакомпании.

---

## 2. Источник данных

Согласно документации проекта (`README.md` и `README_data.md`), использован **синтетический набор данных**, специально сгенерированный для учебного проекта.

Источник формирования данных:
- скрипт `scripts/01_generate_data.py`;
- данные имитируют выгрузку операционной системы авиакомпании;
- в исходной версии присутствуют пропуски и дубликаты;
- после очистки формируется файл `data_clean.csv`.

В модель заложены реалистичные зависимости:

- ухудшение погоды увеличивает вероятность задержки;
- высокая загрузка аэропорта повышает риск задержек;
- задержка предыдущего рейса вызывает каскадные задержки;
- малый запас времени на оборот воздушного судна увеличивает риск;
- пиковые часы и праздничные периоды повышают нагрузку на систему.

## 6. Экономическая оценка

Модель используется для выделения 20% наиболее рискованных рейсов.

Показатели:

| Показатель | Значение |
|------------|----------|
| Тестовых рейсов | 1040 |
| Задержанных рейсов | 284 |
| Отмечено системой | 208 |
| Найдено реальных задержек | 154 |
| Покрытие задержек | 54.23% |
| Годовой экономический эффект | $416,001 |

Вывод:

Модель позволяет заранее выявлять более половины будущих задержек, что даёт расчётный годовой экономический эффект около **416 тыс. долларов США**.

## 8. Заключение

В ходе работы был реализован полный цикл ML-проекта:

- подготовка данных;
- очистка набора данных;
- разведочный анализ;
- обучение нескольких моделей;
- сравнение качества моделей;
- интерпретация признаков;
- расчёт экономического эффекта.

Наилучший результат показала модель Logistic Regression с ROC-AUC 0.846.

Полученные результаты демонстрируют возможность использования моделей машинного обучения для раннего обнаружения риска задержек авиарейсов и поддержки принятия решений операционными службами авиакомпании.
