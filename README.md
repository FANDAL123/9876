# Семестровое расчетное задание по ML

**Тема проекта:** прогноз задержки вылета с экономической оценкой для авиапредприятия.  
**Тип задачи:** бинарная классификация `delayed_15` + дополнительная регрессия `dep_delay_min`.  
**Основной бизнес-вопрос:** какие рейсы имеют повышенный риск задержки 15+ минут и какой экономический эффект может дать раннее предупреждение операционной службы.

## Быстрый запуск на Windows

1. Установить Python 3.10 или 3.11.
2. Распаковать архив проекта.
3. Открыть папку проекта.
4. Дважды нажать `run_all.bat`.

Скрипт сам создаст виртуальное окружение, установит зависимости, заново сгенерирует данные, обучит модели, обновит PDF-отчет и презентацию.

## Ручной запуск

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python scripts/run_all.py
```

## Запуск Jupyter Notebook

```bash
jupyter notebook notebooks/aviation_delay_ml_analysis.ipynb
```

Лучше запускать Jupyter из корня проекта, чтобы относительные пути к `data/`, `scripts/`, `reports/` работали без изменений.

## Важное замечание про данные

Данные являются синтетическими, но построены с реалистичными зависимостями:

- риск задержки растет при плохой погоде;
- риск задержки растет при высокой загруженности аэропорта;
- задержка предыдущего рейса борта усиливает каскадные задержки;
- малый буфер оборота борта повышает риск;
- пиковые часы, праздники и высокая загрузка борта увеличивают операционную сложность.

Такой подход делает работу воспроизводимой: проект можно передать другому человеку, и он сможет получить тот же результат без доступа к закрытым данным авиакомпаний.

## Что говорить на защите

Короткая логика защиты:

1. Задержки рейсов создают прямые операционные расходы.
2. Модель ранжирует рейсы по риску задержки 15+ минут.
3. Лучшие 20% рейсов по риску можно заранее передавать диспетчерской/операционной службе.
4. Бизнес-эффект считается в деньгах: минуты потенциально предотвращенной задержки минус стоимость превентивных действий.
5. Модель не заменяет диспетчера, а дает ранний сигнал, где нужно проверить ресурсы, оборот борта, экипаж, гейт и наземное обслуживание.
